To render offscreen in Vulkan, you need to:

	Create an Offscreen Render Target: Create an image (like a VkImage) that will store the result of your offscreen rendering (this is the target of your post-processing pass).
	Create a Framebuffer: Create a VkFramebuffer that uses the offscreen image as its attachment.
	Configure Render Pass: Set up the render pass to use this offscreen target, specifying the image as the color attachment in the render pass.
	Draw to the Offscreen Target: In the command buffer, start the render pass using the framebuffer, and do your rendering. The results will be written to this offscreen image.
